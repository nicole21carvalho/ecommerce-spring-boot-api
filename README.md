# 🛍️ Loja CCI

Início do back-end de uma loja virtual com **Java e Spring Boot**. O objetivo do projeto é uma loja completa, com front-end em React e Next.js.

## 📌 Estado atual

Por enquanto o repositório tem a aplicação Spring Boot e um primeiro endpoint de teste:

| Método | Rota | Resposta |
|---|---|---|
| `GET` | `/api/` | Mensagem "Olá mundo Spring" com a data e a hora atuais |

## 🛠️ Tecnologias

Java · Spring Boot (Spring Web)

## 📁 Estrutura

```
projetocci/
├── ProjetocciApplication.java   → ponto de entrada da aplicação
└── controller/Hello.java        → endpoint /api/
```
